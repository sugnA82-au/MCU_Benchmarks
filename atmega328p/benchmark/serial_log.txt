                     checksum 01f7cfc8 over 8 passes
  SRAM read (LD)   : 261600 bytes in 163597 us -> 1.599 MB/s
                     checksum 01534b60 over 218 passes
  -> byte reads from flash cost 1.20x what they cost from SRAM.
     LPM is 3 cycles against LD's 2; the rest of the gap is the
     address setup a program-memory read needs and a post-
     incrementing data pointer does not. This part is Harvard:
     flash is a separate address space and a plain C pointer
     cannot see it at all.
  [ OK ] flash read returned data

  -- flash program/erase: not possible from application code --
  SPM only executes from the boot loader section (datasheet 27.4).
  This board runs stock Optiboot 4.4, which exposes no SPM entry
  point, so an application-space erase/program sweep cannot be done
  without replacing the bootloader - which needs an ISP programmer
  this suite does not assume. Substituted below: the 1 KB EEPROM,
  the on-chip non-volatile memory this part CAN write from here.
